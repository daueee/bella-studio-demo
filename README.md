# Bella Studio — demo website

One-page responsive business website (fictional salon), built as a portfolio sample for the "One-Page Contact Website" package.

- Mobile-first, no frameworks, single `index.html`
- WhatsApp booking button + floating chat button
- Contact form (demo; in client projects it posts to an n8n webhook that forwards leads to WhatsApp/email/CRM)
- Embedded Google Map, basic SEO meta tags

Open `index.html` in a browser to view.
